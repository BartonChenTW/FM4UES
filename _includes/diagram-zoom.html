{%- comment -%} Enlarge and open-in-new-tab controls for every Mermaid diagram. Mermaid scales each diagram down to the width of the text column, so a large one (e.g. the ecosystem diagram in 4.11) ends up with unreadably small labels. Under each diagram this adds two buttons: - "Enlarge" (or a click on the diagram itself) opens it in a full-window overlay at readable size, scrollable in both directions. Escape, the close button or a click on the backdrop closes it. - "Open in new tab" opens the diagram as a standalone SVG file, which the browser can zoom freely. The diagrams are rendered client-side by just-the-docs' Mermaid module (and re-rendered by the dark-mode toggle, see mermaid_config.js), so a MutationObserver attaches the controls once the drawing appears, and the buttons always act on the diagram's current drawing. As in nav_footer_custom.html, the script below must not contain a literal HTML tag, even in a comment: lychee's tokenizer loses sync on one. Elements are built with createElement. {%- endcomment -%}
