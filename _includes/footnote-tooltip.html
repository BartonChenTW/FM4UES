{%- comment -%} Footnote hover preview tooltip. Adds a floating tooltip that shows the full reference text when hovering over a footnote number in the main text. Preserves normal click behaviour (jump to footnote section) as fallback. Implementation notes: - Kramdown (Jekyll's default Markdown engine) renders footnote references as: [n] - Footnote definitions are in:
  1. ...
- This script creates a tooltip that clones the footnote content and positions it near the reference on hover/focus. - On touch devices, the native click-to-jump behaviour is preserved. - Uses vanilla JS + CSS, no dependencies. Glossary terms use the same tooltip. A link to a glossary row, written as [term](../appendices/a-glossary.html#term), shows that row's definition on hover. The glossary page is fetched once per page view, and only on pages that have such a link. The anchor is written in the glossary source on the row's bold term, as **Term**{: #term} (a kramdown span attribute, rendered as ). That makes it a real anchor in the built page, so the link still lands on the right row on touch devices or when the fetch fails, and the link checker can resolve it. {%- endcomment -%}
