{%- comment -%} Light/dark mode toggle button. just-the-docs ships both color schemes (assets/css/just-the-docs-light.css and -dark.css, confirmed present in the theme's own assets/css/) and a jtd.setTheme(name) function to swap between them at runtime, but no button, no click handler, and no saved preference across page loads -- all three are added here. jtd.setTheme works by rewriting the href of the page's first [rel="stylesheet"] link to assets/css/just-the-docs-.css (confirmed against the theme's own source). It does not track or persist the current theme itself, so this handler reads the current state via jtd.getTheme(), flips it, calls jtd.setTheme() with the new value, and writes it to localStorage so head_custom.html's script can re-apply it on the next page load before paint. Placed in nav_footer_custom.html per the theme's documented convention for this include. IMPORTANT: the theme renders this include TWICE on every page -- once in the desktop sidebar (components/sidebar.html) and once in the mobile-only footer (components/footer.html, class d-md-none, present in the DOM but display:none above the md breakpoint) -- confirmed by reading both include files directly. Using id="..." here would create duplicate IDs and break document.getElementById in whichever copy isn't first in the DOM, so every element below is selected by class within its own button's subtree instead.
