{% comment %} Renders a small status / last-reviewed badge from page front matter, followed by a link to the page's change history on GitHub. Usage: add `{% include page-status.html %}` right after the page's first H1. Every field is optional, so it's safe to add everywhere. Front matter fields: status: draft | reviewed last_reviewed: 2026-09-11 (YYYY-MM-DD) "Last reviewed" is set by hand when someone has checked the page's content. "Page history" is automatic: it links to the GitHub commit list for this page's source file (repository and branch from _config.yml), so every edit, its date and its diff are traceable without upkeep. {% endcomment %} {% capture page_history_url %}{{ site.gh_edit_repository }}/commits/{{ site.gh_edit_branch }}/{{ page.path }}{% endcapture %}
